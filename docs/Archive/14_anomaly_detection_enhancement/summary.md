- **uv 環境全面移行**: Python 依存関係管理を `uv` に統一し、セットアップ自動化とクロスプラットフォーム互換性を確立した。

## 2. 確定した決定と理由

1. **Python 環境管理の `uv` 移行**:
   - *決定*: `requirements.txt` / システム Python 依存を排し、`uv` によるプロジェクト隔離・仮想環境管理を採用した。
   - *理由*: 初学者の環境構築トラブル（パッケージ競合、バージョン不一致）を最小化し、高速かつ決定論的な依存関係解決を実現するため。
2. **検出器の Python 自前実装**:
   - *決定*: R スキル（`r-anomary-detection`）のアルゴリズム（FastMCD, STL 分解, PSI）を Python（scikit-learn, statsmodels, NumPy）上に忠実に移植した。
   - *理由*: R 実行環境への依存をなくし、Python 単体で完結する可搬性を確保するため。
3. **Score Fusion（統合スコア）の仕様統一**:
   - *決定*: 各検出器のスコアを経験累積分布関数（ECDF）または正規化確率に基づき [0, 1] にスケーリングし、重み付け統合する方式を標準化した。
